# Leopardfish Intel: Tactical Ember Rebuild

## 🚀 How to Sync Your Files

These files are currently in your **Firebase Studio Cloud Workspace**. To get them onto your physical computer, follow this workflow:

### 1. Push changes from the Cloud to GitHub
Run these commands in the **terminal at the bottom of this screen**:
```bash
cd /Users/roger.keen/LI-Project
git add .
git commit -m "Tactical Ember Rebuild"
git push origin main
```

### 2. Pull changes to your Physical Computer
Open the terminal on your **Mac/PC** inside your project folder and run:
```bash
git pull origin main
```
